Mocha 12 is now ready for use in production environments.

<PackageManagers dev type="add" pkg="mocha@12.0.0" />

Below is a migration guide, including breaking changes, notable new features,
and some bugfixes we're proud of.

We will continue to support critical bugfixes in Mocha 11 while customers upgrade to Mocha 12. We've also deployed [v11.mochajs.org](https://v11.mochajs.org) for users that may rely on Mocha 11 in the long-term.

<a id="breaking-changes"></a>

## Breaking changes

- [Bump minimum Node.js version from 18.18.0 to 20.19.0 and 22.12.0
  (#5477)](https://github.com/mochajs/mocha/issues/5477):
  We know that Node 20 is now EOL,
  but we didn't want to jump 2 LTS versions in one release.
  Mocha 13 will drop support for Node 20.
  The new minimum versions are the lowest Node versions that support `require(esm)`.
- [Change root `package.json` type to `module`
  (#6078)](https://github.com/mochajs/mocha/pull/6078):
  Mocha is now an ESM-first package.
  This means `require('mocha')` now returns an object, not a function.
  To workaround this, change `const Mocha = require('mocha')`
  to `const { Mocha } = require ('mocha')`.
  See also [#6245](https://github.com/mochajs/mocha/issues/6245)
- [Change the default of `--forbid-only` to check for process.env.CI
  (#5496)](https://github.com/mochajs/mocha/issues/5496):
  This should improve CI runs, but rare use-cases may need to
  explicitly set `--no-forbid-only` to restore the previous default behavior.
- [Remove `util.inherits` / convert to classes
  (#5025)](https://github.com/mochajs/mocha/issues/5025):
  Through Mocha 11, reporters inherited behavior through `util.inherits`.
  This was deprecated a long time ago.
  Reporters now inherit through canonical `class` syntax.
  This means that the syntax for custom reporters has changed,
  but the core behavior is the same. See the updated
  [third-party reporters](https://mochajs.org/explainers/third-party-reporters/)
  page for details.
- [Replace `he` dependency with manual HTML encoding (#6129)](https://github.com/mochajs/mocha/issues/6129):
  `he` was used for HTML encoding in some reporters, and in the exported `escape` function.
  The new approach should be functionally the same,
  but this was marked as a breaking change out of an abundance of caution.
- Replace `yargs` with custom and native logic:
  `yargs` and its related packages parsed command-line input to Mocha.
  The new approach should be functionally the same,
  with potential minor formatting differences
  in human-facing output like `--help`.
  These were marked as breaking changes out of an abundance of caution.
  - [Replace yargs-parser in CLI option loading (#6124)](https://github.com/mochajs/mocha/pull/6124)
  - [Replace yargs-unparser in CLI respawn paths (#6125)](https://github.com/mochajs/mocha/pull/6125)
  - [Replace yargs with Node.js util.parseArgs (#6164)](https://github.com/mochajs/mocha/pull/6164)
- [Remove `bin/_mocha` and convert `bin/` and entry points to ESM
  (#6017)](https://github.com/mochajs/mocha/pull/6017):
  The `_mocha` entry point had been kept as a workaround for old coverage providers.
  Swapping `path/to/bin/_mocha` with `mocha` should work without issue.
- [Remove unused legacy `errors.js` functions
  (#5835)](https://github.com/mochajs/mocha/pull/5835):
  The public function `createInvalidPluginError` has been deprecated for years.
  Callers should use `createInvalidLegacyPluginError` instead,
  which has the exact same contract and behavior.
- [Cleanup references of `--compilers`
  (#5403)](https://github.com/mochajs/mocha/issues/5403):
  This flag had been deprecated for a long time.
  It had not had any impact on behavior for years.
  It is now removed from the codebase.
- [Cleanup references of `--opts`
  (#5243)](https://github.com/mochajs/mocha/issues/5243):
  This flag had been deprecated for a long time.
  It had not had any impact on behavior for years.
  It is now removed from the codebase.

## Notable new features

- [Allow FIFOs as test files (#5512)](https://github.com/mochajs/mocha/issues/5512)
- [Add ESM export for browsers (#5527)](https://github.com/mochajs/mocha/issues/5527):
  This has since been renamed `mocha.js` but it still works for use in the browser!
- [Add `--fail-hook-affected-tests` option to report skipped tests as failed
  (#5519)](https://github.com/mochajs/mocha/issues/5519)

## Notable fixes

- [Allow importing ESM interface and reporters (#5563)](https://github.com/mochajs/mocha/issues/5563)
